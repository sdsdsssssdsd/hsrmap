判定层：全项目唯一的口径「能不能拿到」而不是「写得详不详细」

每个点位先问两个问题：要不要第二阶段（到了就能拿，还是到了还得动手），再看手上证据补上了 范围 / 位置 / 解法 里的哪几种。

维度一 · 完成要求

LOCATE_ONLYLOCATE_AND_SOLVE
LOCATE_ONLY = 走到就能拿，位置证据本身就是完整攻略。
LOCATE_AND_SOLVE = 到了还得动手，另需解法。

维度二 · 要动手的话，是哪一种

NONEINTERACTINPUT_SEQUENCEMODULE_PUZZLETRANSFORM_ROUTEPLATFORM_ROUTECHALLENGEOTHER

六种状态

NO_EVIDENCESCOPE_ONLYLOCATE_MISSINGLOCATE_COMPLETESOLVE_MISSINGCOMPLETE
绿色两种算「玩家拿得到」。不搞百分比——分数没有稳定语义。

若虫 · 第 1 阶段就到手

位置即全部难点，官方点位图就是完整攻略。

  1. 官方地图上有点位
  2. 玩家走过去
  3. 直接收集

→ COMPLETE

浮脂溯源 · 第 2 阶段还要解

官方图只解决「在哪」，不解决「怎么转」。

  1. 官方点位图告诉你在哪
  2. 玩家走到机关前
  3. 还得按 Q 顺时针 / E 逆时针转对

→ 只有位置 = SOLVE_MISSING；位置 + 旋转序列 = COMPLETE
